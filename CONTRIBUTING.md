# Contributing

Thanks for your interest in this project. It started as a personal/portfolio build, but issues and pull requests are welcome.

## Reporting bugs

Open an [issue](../../issues/new) with:

- A clear description of the problem
- Steps to reproduce it
- What you expected to happen vs. what actually happened
- Your browser/OS if it's frontend-related

## Suggesting features

Open an issue describing the feature and why it'd be useful. Not every suggestion will fit the project's scope, but all are welcome.

## Pull requests

1. Fork the repo and create your branch from `main`.
2. Keep changes focused — one logical change per pull request.
3. Match the existing code style.
4. Describe what you changed and why in the PR description.
5. Make sure the project still builds/runs before submitting.

## Code of Conduct

This project follows a [Code of Conduct](CODE_OF_CONDUCT.md). Please be respectful in all interactions.
