# Security Policy

## Reporting a Vulnerability

If you find a security vulnerability in this project, please report it privately rather than opening a public issue.

**Contact:** fazalabbas2002@gmail.com

Please include:

- A description of the vulnerability and its potential impact
- Steps to reproduce it
- Any relevant logs, screenshots, or proof-of-concept code

I'll do my best to respond within a few days and will let you know once it's addressed.

## Scope

This is a personal/portfolio project. Please use good judgment — this policy covers genuine security issues (e.g. exposed credentials, injection vulnerabilities, auth bypasses), not general bugs (use the regular issue tracker for those).
